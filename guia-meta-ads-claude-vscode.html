Antes de empezar

Lo que necesitas tener listo

Revisa esta lista antes de iniciar. Si te falta algo, el resto de la guía te indicará dónde conseguirlo.

Acceso a Business Manager

Necesitas rol de administrador (o al menos acceso a la cuenta publicitaria con permiso ads_management o ads_read) sobre el portafolio de negocio que vas a conectar.

Cuenta de Claude activa

Un plan Claude Pro, Max, Team o Enterprise (o acceso a la API de Anthropic con facturación configurada). El plan gratuito no permite conectar herramientas externas.

Visual Studio Code

Versión 1.98 o superior. Si ya lo tienes instalado, verifica la versión desde Ayuda → Acerca de.

Node.js 18 o superior

Necesario para instalar el CLI de Claude Code y las herramientas de Meta por línea de comandos (npm).

Sobre esta guía: Meta lanzó sus conectores oficiales de IA para Ads («Meta Ads AI Connectors») el 29 de abril de 2026, en beta abierta. Las capturas, nombres exactos de comandos y flujos de autorización pueden cambiar mientras Meta ajusta la función. Si algún paso no coincide exactamente con lo que ves en tu pantalla, revisa la sección de Solución de problemas y los enlaces oficiales al final de esta guía.
Instalación base

Paso 1 · Instalar Visual Studio Code y Node.js

1

Descargar e instalar Visual Studio Code

VS Code es el editor donde vas a conversar con Claude y ejecutar comandos. Es gratuito y funciona en Windows, macOS y Linux.

Cómo hacerlo, clic a clic
  1. Entra a code.visualstudio.com y haz clic en el botón grande Download for [tu sistema operativo] (se detecta automáticamente).
  2. Ejecuta el instalador descargado y acepta las opciones por defecto (marca la casilla Add to PATH si aparece en Windows).
  3. Abre VS Code una vez termine la instalación.
Resultado esperado: se abre la pantalla de bienvenida de VS Code con el logo azul característico.
2

Instalar Node.js

Node.js incluye npm, el gestor de paquetes que usaremos para instalar el CLI de Claude Code y, más adelante, las herramientas de Meta.

Cómo hacerlo, clic a clic
  1. Entra a nodejs.org y descarga la versión marcada como LTS (recomendada, no la "Current").
  2. Ejecuta el instalador con las opciones por defecto.
  3. Abre una terminal (en VS Code: menú Terminal → New Terminal, o el atajo Ctrl+` / Cmd+`) y confirma la instalación:
node --version
npm --version
Resultado esperado: dos números de versión, por ejemplo v20.x.x y 10.x.x. Si ves «command not found», reinicia VS Code o tu computador y vuelve a intentarlo — a veces el PATH tarda en actualizarse.
Claude en tu editor

Paso 2 · Instalar Claude Code en VS Code

Claude Code puede vivir en VS Code de dos formas complementarias: la extensión (panel gráfico con vista de cambios) y el CLI (línea de comandos, dentro de la terminal integrada). Vamos a instalar ambas, porque la extensión no añade automáticamente claude al PATH de la terminal.

1

Instalar la extensión Claude Code

Cómo hacerlo, clic a clic
  1. En VS Code, presiona Ctrl+Shift+X (Windows/Linux) o Cmd+Shift+X (Mac) para abrir el panel de Extensiones.
  2. Escribe Claude Code en el buscador.
  3. Selecciona la extensión publicada por Anthropic (verifica el nombre del publicador antes de instalar) y haz clic en Install.
  4. Si no aparece el ícono después de instalar, ejecuta Developer: Reload Window desde la Paleta de Comandos (Ctrl+Shift+P / Cmd+Shift+P).
Resultado esperado: aparece un ícono de chispa (✱) en la barra de actividad lateral de VS Code.
2

Instalar el CLI de Claude Code (para usarlo en la terminal)

Esto es lo que necesitas para poder escribir claude directamente en la terminal integrada de VS Code — imprescindible para el resto de esta guía.

Cómo hacerlo, clic a clic
  1. Abre una terminal en VS Code (Ctrl+` / Cmd+`).
  2. Ejecuta:
npm install -g @anthropic-ai/claude-code
  1. Verifica que quedó instalado:
claude --version
Resultado esperado: un número de versión, por ejemplo 2.1.x. Si aparece «command not found», tu carpeta global de npm no está en el PATH — cierra y vuelve a abrir la terminal, o agrega manualmente la ruta que indica npm config get prefix.
Autenticación

Paso 3 · Iniciar sesión en Claude Code

1

Abrir tu carpeta de trabajo

Claude Code trabaja sobre una carpeta (workspace), no sobre archivos sueltos. Crea o abre una carpeta dedicada a este ejercicio.

Cómo hacerlo, clic a clic
  1. Menú File → Open Folder… (o Archivo → Abrir carpeta…).
  2. Crea una carpeta nueva, por ejemplo meta-ads-claude, y ábrela.
2

Iniciar sesión

Cómo hacerlo, clic a clic
  1. En la terminal integrada, escribe:
claude
  1. La primera vez, Claude Code te preguntará cómo quieres autenticarte. Elige la opción que corresponda a tu cuenta: Claude.ai (suscripción), Anthropic Console (API), o tu proveedor institucional (Bedrock/Vertex/Foundry).
  2. Se abrirá tu navegador. Haz clic en Authorize.
  3. Vuelve a VS Code: la terminal debe mostrar el prompt de Claude Code activo.
Resultado esperado: ves el prompt interactivo de Claude Code (una línea con el símbolo >) listo para recibir instrucciones.
Si prefieres el panel gráfico en lugar de la terminal, abre el ícono de chispa (✱) en la barra lateral: la extensión usa la misma sesión iniciada.
El paso clave

Paso 4 · Conectar Meta Ads

Meta ofrece dos vías oficiales para que una IA acceda a tu Business Manager, bajo el nombre Meta Ads AI Connectors: un servidor MCP (pensado para clientes conversacionales) y un CLI propio (pensado para flujos de terminal, como Claude Code). Elige según cómo vayas a trabajar — puedes usar cualquiera, o ambos.

Recomendada para VS Code

Ruta A · CLI oficial de Meta

Se instala como cualquier paquete de npm y Claude Code lo invoca como comandos de terminal. Evita el flujo de autorización por navegador integrado en el agente, así que es la opción más estable para trabajar dentro de VS Code hoy.

  • Autenticación propia (meta login), separada de Claude
  • Ideal para pedirle a Claude que ejecute comandos por ti
  • Ve al bloque Ruta A más abajo
Alternativa

Ruta B · Conector MCP oficial

Se agrega como un servidor MCP remoto dentro de Claude Code. Es la vía pensada para chats de lenguaje natural, pero a la fecha de esta guía presenta fallas conocidas de autorización específicamente en Claude Code (ver aviso más abajo).

  • Autorización vía OAuth de Meta, dentro de Claude
  • Funciona de forma estable en Claude.ai (web) y Claude Desktop
  • Ve al bloque Ruta B más abajo
A

Ruta A — Instalar y autenticar el CLI de Meta Ads

Cómo hacerlo, clic a clic
  1. En la terminal integrada de VS Code (fuera de la sesión de claude, en la línea de comandos normal), instala el CLI de Meta:
npm install -g @meta/ads-cli
  1. Inicia el proceso de autenticación:
meta login
  1. Se abrirá tu navegador con el flujo de inicio de sesión de Facebook Business. Ingresa tus credenciales de Meta Business Manager.
  2. Selecciona el portafolio de negocio y la cuenta publicitaria que quieres conectar, y aprueba los permisos solicitados (como mínimo ads_read; añade ads_management solo si vas a pedirle a Claude que edite campañas).
  3. Vuelve a la terminal y confirma que la cuenta quedó vinculada:
meta accounts list
Resultado esperado: una lista con el ID y nombre de tu(s) cuenta(s) publicitaria(s). Si el comando no existe o el nombre difiere, ejecuta meta --help para ver los comandos disponibles en tu versión — esta CLI está en beta y su superficie de comandos puede cambiar.
Importante: no generes un token manual desde el Explorador de la Graph API y lo pegues en variables de entorno. El flujo oficial meta login maneja la renovación del token por ti; un token manual pegado a mano expira (~60 días) y puede quedar mal alcanzado en permisos.
A2

Que Claude Code pueda usar el CLI de Meta

No necesitas configuración adicional: una vez el CLI está instalado y autenticado en tu máquina, Claude Code puede ejecutarlo como cualquier otro comando de terminal cuando le pidas algo relacionado con tus anuncios.

Cómo hacerlo, clic a clic
  1. En la misma terminal, entra a la sesión de Claude Code:
claude
  1. Escribe una instrucción de prueba: "Usa el CLI de meta para listar mis cuentas publicitarias".
  2. Claude Code te mostrará qué comando quiere ejecutar (por ejemplo, meta accounts list) y pedirá tu aprobación antes de correrlo — esto es normal y es la capa de seguridad por defecto.
  3. Aprueba con y o el botón correspondiente.
Resultado esperado: Claude ejecuta el comando y te responde con los datos reales de tu cuenta, en lenguaje natural.
B

Ruta B — Conectar el servidor MCP oficial de Meta Ads

Cómo hacerlo, clic a clic
  1. Dentro de la sesión de claude (o desde la terminal normal, antes de entrar), registra el servidor MCP de Meta:
claude mcp add --transport http meta-ads https://mcp.facebook.com/ads
  1. Entra o continúa en la sesión de Claude Code y ejecuta el comando de autenticación:
/mcp
  1. Selecciona el servidor meta-ads en la lista y sigue el enlace de autorización que aparece en la terminal.
  2. En el navegador, inicia sesión con tu cuenta de Meta Business, elige el portafolio y la cuenta publicitaria, y aprueba los permisos.
Resultado esperado: /mcp muestra el servidor meta-ads como conectado, con su número de herramientas disponibles.
Aviso conocido: al momento de escribir esta guía, algunos usuarios reportan que el paso 3 falla específicamente en Claude Code (CLI y extensión de VS Code) con un error del tipo redirect_uris not registered, porque Meta solo tiene registradas las direcciones de retorno de Claude.ai (web) y Claude Desktop. Si te ocurre, no es un error tuyo: usa la Ruta A (CLI de Meta) mientras se resuelve, o completa la autorización inicial desde Claude Desktop o claude.ai y continúa el resto del trabajo desde ahí.
Comprobación

Paso 5 · Verificar que todo quedó conectado

1

Revisar el estado desde la terminal

Cómo hacerlo, clic a clic
  1. Si usaste la Ruta A, confirma la sesión del CLI: meta accounts list.
  2. Si usaste la Ruta B, revisa los servidores MCP registrados: claude mcp list.
claude mcp list
# deberías ver algo como:
# meta-ads   https://mcp.facebook.com/ads   ✓ connected
2

Hacer la primera pregunta real

La prueba definitiva no es el estado de conexión, sino si Claude te devuelve datos reales de tu cuenta.

Cómo hacerlo, clic a clic
  1. Dentro de la sesión de Claude Code, escribe:
Muéstrame mis 5 conjuntos de anuncios con mejor ROAS en los últimos 30 días, con al menos 20 conversiones.
Resultado esperado: una tabla o lista con nombres reales de tus conjuntos de anuncios y sus métricas. Si Claude responde con información genérica o inventada en lugar de tus datos, la conexión no está activa — vuelve al Paso 4.
Ya conectado

Paso 6 · Instrucciones de ejemplo para empezar a practicar

Empieza siempre por instrucciones de lectura (reportes, diagnóstico) durante tus primeras sesiones, y solo pasa a instrucciones de escritura (crear o editar campañas) cuando entiendas bien qué está haciendo Claude en cada paso.

Reportes y análisis (lectura)

"Compara el CPA de mis últimas 3 campañas activas y dime cuál está por encima del promedio."

Diagnóstico de señales

"Revisa si mi Pixel y la API de Conversiones están duplicando o perdiendo eventos de compra."

Edición de presupuesto (escritura)

"Reduce en 20% el presupuesto diario de los conjuntos de anuncios con CPA mayor a $8, pero muéstrame primero cuáles son antes de aplicar el cambio."

Pausar anuncios (escritura)

"Pausa todos los anuncios con frecuencia mayor a 4 en los últimos 7 días y confírmame la lista antes de pausar."

Antes de dar acceso de escritura

Buenas prácticas de seguridad

  • Empieza con el permiso ads_read únicamente. Añade ads_management solo cuando de verdad vayas a pedirle a Claude que cree o edite algo.
  • Usa siempre los flujos oficiales de autenticación (meta login o el OAuth de /mcp). Nunca copies y pegues un token de acceso generado a mano en un archivo de configuración.
  • Mantén siempre un humano revisando: antes de aprobar una acción de escritura, pídele a Claude que te muestre exactamente qué campañas, conjuntos o presupuestos va a tocar.
  • Trabaja desde una cuenta de Business Manager verificada, no desde un perfil personal sin verificación.
  • Si dejas de usar el conector por un tiempo, desactívalo (claude mcp remove meta-ads o cierra sesión con meta logout) en lugar de dejarlo autorizado indefinidamente.
Cuando algo no sale como se espera

Solución de problemas

SíntomaCausa probableQué hacer
Error redirect_uris not registered al autorizar el MCP en Claude Code Meta aún no registra las URLs de retorno locales que usa Claude Code (CLI y extensión de VS Code). Usa la Ruta A (CLI de Meta) o completa la autorización desde Claude Desktop / claude.ai y sigue trabajando desde ahí.
La cuenta aparece pero con is_ads_mcp_enabled: false El despliegue de Meta es gradual; tu cuenta aún no está habilitada en la lista de acceso. Espera unos días e inténtalo de nuevo — no es necesario reconfigurar nada.
Error de validación al crear un anuncio de generación de leads (Error 100 / 1815089) No has aceptado los Términos de Servicio de Lead Ads. Visita facebook.com/legal/leadgen/tos, acepta los términos, y repite la acción.
claude o meta no se reconocen como comando La carpeta global de npm no está en el PATH de tu terminal. Cierra y reabre la terminal. En Windows verifica con npm config get prefix que esa ruta esté en tus variables de entorno.
Claude responde con datos genéricos, no de tu cuenta real El conector no está realmente conectado, aunque parezca estarlo. Corre claude mcp list o meta accounts list para confirmar el estado antes de seguir.
Las respuestas se vuelven lentas o imprecisas tras varias preguntas El MCP de Meta envía datos de la API sin filtrar en cada respuesta, lo que llena el contexto de la conversación. Empieza una conversación nueva cada pocas preguntas, o desconecta el MCP cuando no lo estés usando.

Glosario

MCP (Model Context Protocol)
Estándar abierto que define cómo un asistente de IA descubre y llama herramientas externas — en este caso, las funciones de Meta Ads.
Meta Ads AI Connectors
Nombre oficial de Meta para el conjunto de MCP + CLI que conecta cuentas publicitarias con asistentes de IA.
Business Manager
El panel central de Meta donde se administran cuentas publicitarias, páginas y permisos de un negocio.
ads_read / ads_management
Permisos de la Marketing API: el primero solo permite leer datos, el segundo permite además crear y editar.
OAuth
Protocolo de autorización que permite iniciar sesión con tu cuenta de Meta sin compartir tu contraseña con la herramienta externa.
Claude Code
El agente de Anthropic que ejecuta tareas dentro de tu editor o terminal, con acceso a archivos y a herramientas conectadas.
